Repositorio de tareas, laboratorios y parciales del curso de **Diseño Electrónico**.

## Contenido

Este repositorio incluye:
- Tareas y ejercicios del curso
- Exámenes parciales
- Proyectos y laboratorios

Los archivos pueden incluir esquemáticos, simulaciones de circuitos, reportes técnicos y cualquier entregable relacionado con el curso.

## Propósito

Este repositorio tiene como objetivo llevar un registro organizado de los trabajos realizados a lo largo del curso, sirviendo como portafolio académico y respaldo de los entregables.
